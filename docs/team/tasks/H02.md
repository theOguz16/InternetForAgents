# [H02] Trace metric ve structured logging ekle

## Amaç

S1.0 planındaki **H02** teslimini tamamlamak. Bu işin somut hedefi: Job-step-dispatch-task bağlantısını taşı.

## Başlamadan önce

- Durum: Bağımlılıklar tamamlanınca başlanabilir.
- Ürün/mimari lideri ve son review: **Oguzhan**. Uygulayıcı henüz atanmadı; issue sahiplenilmeden paralel aynı işe başlamayın.
- Bağımlılıklar: **D01,E10**. Bağımlı kontrat tamamlanmadan varsayım yapmayın; planınızı issue yorumunda paylaşın.
- Okuma: `docs/stage-1/08-evaluation.md`, `docs/stage-1/README.md`, `docs/team/working-agreement.md`.
- Başlangıç noktaları: `tests/platform.test.cjs, tests/manifest.test.cjs, docs/development/persistence.md`. Dosya yoksa ilgili bağımlılık henüz teslim edilmemiş olabilir.

## Yapılacaklar

1. Job-step-dispatch-task bağlantısını taşı.
2. Latency/queue/outcome metriği çıkar.
3. Sentetik veriyle trace akışını göster.

4. Başarı ve hata akışlarını ayrı düşünün; gerekli Türkçe yorumlarla nedenini açıklayın.
5. API/şema/veri değişiyorsa örnekleri, belgeyi ve migration etkisini aynı PR’da güncelleyin.

## Kabul kriterleri

- [ ] Bir job’ın uçtan uca izi bulunur.
- [ ] Secrets yok.
- [ ] Metric label cardinality sınırlı.

- [ ] İlgili S1.0 kabul/tehdit maddesine kanıt bağlantısı eklendi.
- [ ] Mevcut davranışın neden korunduğu veya nasıl migrate edildiği açıklandı.

## Test ve teslim kanıtı

Node.js 24 kullanın. `npm ci`, `npm run build`, `npm run test:services` temel kontrollerdir. Bu task için yukarıdaki her kabul maddesine en az bir otomatik test veya tekrarlanabilir deney senaryosu bağlayın. Güvenlik ve veri task’larında negatif senaryo zorunlu; UI task’larında screenshot ve klavye akışı; benchmark task’larında ham veri ve run manifesti ekleyin. Çalıştırılmayan kontrolleri başarılı gibi göstermeyin. Test DB/portlarını geçici oluşturun; ekip verisini silmeyin.

## Kapsam dışı

Bu issue dışındaki profilleri veya servisleri baştan yazmak, gereksiz yeni framework eklemek, genel internet deployment yapmak ve veri/secret paylaşmak bu işin parçası değildir. Başka task’a ihtiyaç çıktıysa Oguzhan’a somut gerekçeyi ve en küçük bağımlılığı bildirin. Teslim B/C özelliklerini bu PR’a katmayın.
