Node.js 24 kullanın. `npm ci`, `npm run build`, `npm run test:services` temel kontrollerdir. Bu task için yukarıdaki her kabul maddesine en az bir otomatik test veya tekrarlanabilir deney senaryosu bağlayın. Güvenlik ve veri task’larında negatif senaryo zorunlu; UI task’larında screenshot ve klavye akışı; benchmark task’larında ham veri ve run manifesti ekleyin. Çalıştırılmayan kontrolleri başarılı gibi göstermeyin. Test DB/portlarını geçici oluşturun; ekip verisini silmeyin.

Başka task’a ihtiyaç çıktıysa Oguzhan’a somut gerekçeyi ve en küçük bağımlılığı bildirin. Teslim B/C özelliklerini bu PR’a katmayın.
